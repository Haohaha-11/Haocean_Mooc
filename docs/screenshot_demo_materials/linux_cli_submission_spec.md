# Linux 命令行作业流程报告

请提交一份 Markdown 文档，说明你如何在 Linux 终端中完成一次课程作业提交。作业重点不是写很多字，而是把真实命令、文件组织和提交前检查讲清楚。

## 提交文件

在本作业对应的 workspace 目录中提交：

- `answer.md`

## 写作要求

`answer.md` 至少包含以下内容：

1. 你用哪些命令查看老师发布的作业和附件。
2. 你如何下载并阅读作业要求。
3. 你如何组织本地作业目录和答案文件。
4. 你如何在提交前用 `preview` 检查即将打包的文件。
5. 你如何正式提交作业。
6. 用一小段话说明这种 Linux 命令行作业流带给你的体会。

## 建议结构

```markdown
# Linux 命令行作业提交说明

## 1. 查看作业和附件

## 2. 准备本地文件

## 3. 预览和提交

## 4. 学习体会
```

## 评分标准

- 命令流程完整：30 分
- 文件组织清楚：20 分
- 提交前检查说明清楚：20 分
- 学习体会具体：20 分
- Markdown 排版规范：10 分
